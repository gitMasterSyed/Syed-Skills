# Contributing to Syed Sajid Portfolio

Thank you for your interest in contributing to this project! This project has been simplified to a single-file architecture to remove the need for complex build tools.

## 🛠️ Development Workflow

1. **Open the code**: Direct edits can be made to `index.html`.
2. **Setup your environment**: No `npm install` is required for basic changes. 
3. **Local Testing**: Open `index.html` directly in a browser or use a simple static server.
4. **Consistency**: Ensure any new components are added within the existing React structure in `index.html`.

## 🎨 Styling Guidelines
- Use **Tailwind CSS Utility Classes** via the CDN script.
- Follow the existing **Slate/Cyan** color palette.

## 📦 Pull Request Process
- Since this is a single-file app, keep the code legible and well-commented inside the script tag.
- Ensure all icon names correspond to valid entries in the Lucide library.

---
*Note: This is a personal portfolio. Major structural changes or content updates are usually handled by the owner.*
